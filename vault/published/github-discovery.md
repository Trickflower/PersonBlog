星数能反映关注度，但不能单独判断一个项目是否适合自己的工作。

## 区分三种信号

| 信号                              | 能说明什么         | 不能直接说明什么     |
| --------------------------------- | ------------------ | -------------------- |
| 当前 Stars 超过 10,000            | 累积了较高关注度   | 最近一个月增长了多少 |
| 最近一个月有推送                  | 仓库近期有活动     | 项目最近爆火         |
| 最近一个月新建且超过 10,000 Stars | 新项目快速获得关注 | 稳定性与长期维护情况 |

要观察月增长，需要有两个时间点的星数记录，并标明实际采样区间。

## 阅读项目时

1. 从 README 确认项目解决的问题和运行方式。
2. 查看许可证，理解使用条件。
3. 查看发布记录与近期 Issues，判断维护状态。
4. 用最小案例试用，记录限制和真实效果。

试用过程可以写成 [[markdown-notes|带代码的笔记]]，再与 [[connected-notes|相关知识]] 建立链接。
